## Evidence levels and freeze rule

- **V**: implemented and supported by an executed local check reported in a retained artifact or dated verification record.
- **I**: implemented in inspected source, with test code or historical evidence; a fresh execution/recording is still required for the precise delivery snapshot.
- **P**: partial capability or partial native demonstration.
- **F**: future work with no inspected complete implementation.
- **B**: blocked by an environment prerequisite.

A test source file proves the intended assertion exists. A screenshot proves an observed page. A recording proves only the actions/outcomes actually visible. None alone proves production reliability, full security/accessibility compliance, or business value. Freeze final counts and clip paths in the presentation readiness record after the final runtime checks.
