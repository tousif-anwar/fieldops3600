# Operations web

React + TypeScript + Vite, with Fluent UI, TanStack Query, React Router, React Hook Form, Zod, Recharts, and SignalR. Real service responses drive every screen; service failures are displayed rather than replaced with fixtures.

```powershell
npm ci
npm run dev
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

Development uses port 5173 and proxies `/api` and `/hubs` to the gateway at `localhost:5100`. Container hosting uses the root Compose configuration. Copy `.env.example` only when changing the local defaults. The web client uses Keycloak's public `fieldops-web` client, authorization code flow with PKCE. Register `/auth/callback` for each permitted web origin. Access and refresh tokens remain in memory; only PKCE transaction state uses session storage. Refreshing the page requires signing in again through the existing identity-provider session. Never configure a client secret in browser environment variables.

Implemented routes: overview, work orders, work order creation/details, schedule/recommendations/booking, technician jobs and eight-stage forms, supervisor controls, notifications, warehouse analytics, replay, and identity-administration link. Role-aware navigation is a convenience; APIs enforce access independently.

Drafts store selected form options in browser local storage under user + workflow + stage keys. They never contain access tokens. Drafts do not submit automatically, bypass stage ordering, or stop the authoritative server SLA. Failed submissions retain the answers and idempotency key; a successful stage submission clears the local draft. Concurrent-state conflicts show the service's error and a reload action.

Replay playback consumes the dedicated read-model order and only reduces event evidence into historical state. It does not send workflow commands. Filters use original occurrence time. Delivery attempts remain attached to their logical event, late arrivals are marked, and occurrence/recorded/received/processed timestamps remain separate. Jaeger links retain trace IDs even when the external trace retention window has expired; the UI explains retention instead of claiming the trace exists. Incident CSV/PDF exports are generated by the authorized API.

Advisory SLA prediction is a supervisor disclosure. Stage and elapsed time come from the workflow; other model inputs are explicitly editable assumptions requiring review. Predictions call the real intelligence endpoint, display model version and synthetic-training limitations, and never mutate operational state or rank employees.

Component/unit tests cover order validation/mutations/server rejection, conditional fields, pause countdown, access errors, historical state boundaries, late-event filters, immutability of replay input, and retry grouping. Playwright checks unauthenticated route protection and login responsiveness. Full signed-in end-to-end verification requires the Compose services and an identity-provider account; the login checks do not claim to verify the distributed lifecycle.

Accessibility: semantic headings, labels, visible keyboard focus, a skip link, text-based status indicators, form validation, accessible notification counts, native playback range, and reduced-motion support. A complete WCAG audit has not been performed. Supervisor intervention uses Fluent Dialog focus trapping and escape handling.
